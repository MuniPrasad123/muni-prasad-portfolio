Investigation · first to last

    What is GC? Watch a small heap example

    The heap holds Java objects. A reachable object is still connected to the application; it must remain. Unreachable objects can be reclaimed. Some GC phases pause Java application threads, while other phases run concurrently.

    Six reachable objects and six unreachable objects. This is a picture, not a measured heap.

    Why a healthy average can hide slow checkouts

    Constructed set: 98 requests take 200 ms; two take 2,000 ms. Mean = 236 ms; nearest-rank p99 = 2,000 ms. This teaches percentiles, not an observed result. Never average per-server percentiles to obtain a fleet percentile.

    Explore allocation pressure without predicting GC pauses

    Multiplication counts hypothetical objects, not bytes. Object sizes, lifetimes, heap, collector and CPU also matter. This cannot predict pause frequency or duration and never changes the evidence above.
